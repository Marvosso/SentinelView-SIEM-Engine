# SentinelView: Security Intelligence Engine
A Python-based SIEM designed to bridge the gap between technical telemetry and business governance.

### Features
* **Nexus AI Brain:** Translates raw system logs into "Plain English" remediation steps.
* **PII/Sensitive Data Detection:** Automatically flags potential exposure of PII, PCI, or PHI.
* **Evidence Pulse:** Real-time system monitoring to ensure continuous audit readiness.
